# THOKAR ZERO 5.1

Refinement release focused on daily workshop use.

- Swipe delete closes when tapping elsewhere and only one row can remain revealed.
- Deleting a vehicle also removes all associated work records, including completed jobs.
- Clipboard plate comparison ignores the verification digit after a hyphen (for example ZV9245 and ZV9245-2 match).
- Monetary inputs use Chilean thousands grouping from $1.000 upward while values below 1.000 remain unpadded.
- Record editor adds service date and optional next-maintenance date.
- Save button no longer floats above the Android keyboard.
- Red ambient background is precomposed without blur to avoid delayed compositing.
- PWA/package naming is THOKAR ZERO, without the previous iOS label.
