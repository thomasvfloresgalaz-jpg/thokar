# THOKAR · iOS 26 Prototype

Experimento visual independiente de la RC1.

- Conserva datos, backend, consultas, chat, Registro, Datos y cotizaciones.
- Sustituye la presentación por una interfaz inspirada en patrones actuales de iOS 26: jerarquía de títulos, superficies agrupadas, barras flotantes, hojas inferiores y Liquid Glass.
- Build: thokar-ios26-prototype-1
- Cache: thokar-ios26-prototype-1
- Pruebas: 50/50 al generar el paquete.

No se considera THOKAR 1.0 oficial. Es un prototipo alternativo para comparar visualmente con RC1.
