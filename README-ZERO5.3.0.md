# THOKAR ZERO 5.3.0 — ventanas con arrastre y encaje adaptativo

- Las ventanas usan la altura del viewport visual, y se anclan al borde inferior visible justo por encima de la navegación del dispositivo. No se suma una reserva ficticia de 48 px.
- Apertura de hojas en 78% máximo o altura natural si son cortas; tirador superior real de 34 px con gestos para ampliar, contraer y cerrar. Pulsarlo alterna tamaño, y admite flechas del teclado.
- Las acciones de detalle de trabajo y el compositor del chat quedan en un pie independiente; el contenido se desplaza dentro de la hoja.
- Ajuste de teclado Android y cambios de viewport sin volver a dibujar la pantalla.
- Se conservan todos los datos locales, las consultas de repuestos persistentes, los registros, el historial, el logotipo y el backend.
- Validar en Samsung real tanto navegación por botones como por gestos antes de publicar ampliamente.
