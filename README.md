# THOKAR — iOS Zero Prototype

Proyecto visual escrito desde cero para probar una dirección iOS completamente distinta. No contiene archivos copiados de los prototipos THOKAR anteriores.

## Navegación
Cinco destinos: Resumen, Autos, acción central Nueva atención, Bitácora y Ajustes.

## Backend
La consulta intenta usar `GET /api/vehiculo/:patente`. El resto del prototipo es frontend independiente. Para convertirlo en reemplazo funcional completo de THOKAR habrá que integrar, de forma deliberada, las APIs y persistencia reales sin copiar la interfaz anterior.
