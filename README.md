# THOKAR ZERO 5.2.2

Hotfix funcional sobre ZERO 5.2.1.

- El diagnóstico de una orden pendiente se sincroniza automáticamente con cada respuesta de Diagnosticar con THOKAR, incluso si existe un borrador antiguo del registro.
- Los registros marcados como Listo quedan congelados y no reciben actualizaciones automáticas.
- Swipe espejo para vehículos activos: izquierda→derecha revela Archivar en azul claro; derecha→izquierda conserva Eliminar en rojo.
- El cierre de ambos gestos usa animación inversa y solo puede quedar una acción abierta.
- En Inicio, Archivados ya no ocupa una tarjeta permanente: se revela como control pequeño al realizar un gesto ascendente rápido y desaparece después.
- Archivar conserva ficha, trabajos, diagnóstico, tareas y chat; eliminar sigue borrando todo el vehículo.
- Buscar una patente archivada la reactiva con su historial.

Build: ZERO 5.2.2.
