# Cambios de THOKAR ZERO 5.5.0

- Sección Chats: un historial técnico por patente, encabezado marca/modelo, búsquedas y chats archivados accesibles.
- Interfaz ChatGPT-like de pantalla completa, adaptada al teclado Android; mensaje preservado si la IA falla.
- Diagnóstico de orden independiente de la conversación técnica; ningún mensaje rellena automáticamente la explicación del cliente.
- Redactor de diagnóstico no técnico con vista previa y aprobación obligatoria.
- Consultas rápidas Gemini: modelo Flash rápido primero, segundo intento condicionado y temporizadores coordinados.
- Eliminación visual de las herramientas recientes no utilizadas y mantenimiento de datos.
- Caché de PWA e identificación actualizados.

Consulta `README.md` para migración y verificaciones.
